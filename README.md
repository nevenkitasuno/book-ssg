Генератор статического сайта-блога

[Пример блога](https://nevenkitasuno.github.io/blog-ssg/) , сгенерированного по папке `/examples/content`

- Ведите несколько блогов на одном хостинге
- Подарите подходящий стиль каждому блогу с помощью простых настроек
- Движок генерирует статический сайт, что позволяет бесплатно размещать его на некоторых хостингах
- Добавлен синтаксис для риичи-маджонга. Можно расширить кастомными шрифтами для любой сферы

## Запуск

```bash
go run ./cmd/ssg --content path/to/content/dir/ --output path/to/desired/output/dir/
```

# Контент

## Структура папки с контентом

Пример:

```
examples/content/
  style.css
  favicon.ico
  cooltopic/
    2026-05-03-some-post/
      1.md # yoursite.com/cooltopic/some-post
      2.md # yoursite.com/cooltopic/some-post-2 – вторая страница
      preview.png # это изображение будет в качестве превью
      some-pic.png # можно использовать в тексте как ![[some-pic.png]]
    2026-05-03-second-post/
      1.md
    meta/
      Config.yaml # настройки цветов и прочего
      Links.md # ссылки которые отобразятся в шапке
      top_banner.png # изображение для шапки
      some-other-page.md # на эту страницу можно вставить ссылку в Links.md
  other-cool-topic/
	...
```

- каждая папка первого уровня внутри `content` считается темой;
- публикации имеют формат каталога `YYYY-MM-DD-slug`;
- страницы публикации называются `1.md`, `2.md`, `3.md` и так далее;
- `meta/Links.md` задаёт ссылки в шапке темы;
- `meta/*.md` могут публиковаться как отдельные служебные страницы темы.

## Структура публикации

Чтобы не заморачиваться лишний раз над заголовком и текстовым превью:
- Заголовок публикации берётся из первого `# ...` в `1.md`.
- Первый абзац текста публикации используется для текстового превью

### Особенности markdown

Поддерживается подсветка синтаксиса языков программирования

Изображение можно вставить просто положив его в папку публикации и указав в тексте

```
Вот такого крутого кота сегодня встретил

![[кот.png]]

Правда красавец?
```

Специально для маджонга сделал поддержку особых тегов. По идее можно расширить на любой шрифт. С маджонгом работает так:

```
На сбросе игрока слева можно объявить чи, например [font="Riichi-Mahjong-Colorful"][rot-90]5p*[/rot-90]🀛🀜[/font]. В данном случае игрок слева (шимоча) сбросил акадору.
```

Это пример чи, объявленного на акадоре 5 pin. Тег `rot-90`  делает тайл, да и любой другой символ, лежащим. Как писать разные тайлы можно уточнить на [странице шрифта](https://github.com/rutopio/Japanese-Mahjong-Font-with-OpenType/).

## Простой вариант стилизации блога

- Придумать идею
- Найти под неё картинку на верхний баннер которая настраивает на нужный лад
- Скинуть в нейросеть картинку, Config.yaml и style.css, попросить подобрать цвета на основе картинки, и чтобы нейросеть сразу указала их в виде Config.yaml
