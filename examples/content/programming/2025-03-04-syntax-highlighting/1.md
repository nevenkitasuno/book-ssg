# Подсветка синтаксиса

Пост в тот же день кстати

Пример кода на lisp

```lisp
(defun calculate-hypotenuse (x y)
  "Calculates the square root of the sum of the squares of x and y."
  (sqrt (+ (* x x) (* y y))))

;; Usage:
(calculate-hypotenuse 3 4) ; Returns 5.0
```
